# 仓库管理系统 - 使用说明

## 一、项目简介

这是一个基于 React + TypeScript + Vite 开发的仓库管理系统，包含以下功能模块：

- **库存管理**：库存查询（汇总/批次）、盘点管理、库存流水记录
- **入库管理**：采购入库、自制入库、归还退库、调拨入库
- **出库管理**：领用出库（低值易耗/展会物资）、报废出库、报损出库
- **调拨管理**：仓库间调拨、展会物资调拨
- **固定资产**：资产档案、资产领用、资产调拨、资产报废
- **基础资料**：仓库管理、仓位管理、物资档案、供应商管理
- **报表管理**：库存报表、入库汇总、出库汇总、库龄分析、呆滞分析
- **反确认功能**：支持入库单、出库单、调拨单、报废单、报损单的反确认操作

## 二、环境要求

请确保您的电脑已安装以下软件：

| 软件 | 版本要求 | 下载地址 |
|------|---------|---------|
| Node.js | 18.x 或更高版本 | https://nodejs.org |
| npm | 随 Node.js 自动安装 | - |

**验证安装：**
打开命令行（CMD 或 PowerShell），输入：
```
node -v
npm -v
```
能看到版本号即表示安装成功。

## 三、运行步骤

### 步骤1：解压项目
将收到的项目文件夹解压到任意目录，例如：`D:\warehouse-management`

### 步骤2：安装依赖
打开命令行，进入项目目录：
```
cd D:\warehouse-management
npm install
```
等待安装完成（约1-3分钟）。

### 步骤3：启动项目
```
npm run dev
```

### 步骤4：访问系统
打开浏览器，访问：http://localhost:5174

## 七、常见问题

### Q1：npm install 报错？
- 检查 Node.js 版本是否 >= 18
- 尝试清除缓存：`npm cache clean --force`
- 使用国内镜像：`npm config set registry https://registry.npmmirror.com`

### Q2：端口被占用？
项目默认使用 5174 端口，如被占用：
- 修改 `vite.config.ts` 中的 `port` 配置
- 或关闭占用端口的程序

### Q3：页面空白？
- 检查是否正确执行了 `npm install`
- 检查浏览器控制台是否有报错

## 八、反确认功能说明

### 8.1 功能概述

反确认功能允许用户对已提交或已确认的单据进行撤销操作，将单据状态回退到可编辑状态。

### 8.2 适用范围

| 单据类型 | 支持反确认 | 说明 |
|---------|----------|------|
| 采购入库单 | ✅ | 可反确认已提交/已确认的入库单 |
| 自制入库单 | ✅ | 可反确认已提交/已确认的入库单 |
| 归还退库单 | ✅ | 可反确认已提交/已确认的退库单 |
| 领用出库单 | ✅ | 可反确认已提交/已确认的出库单 |
| 报废出库单 | ✅ | 可反确认已提交/已确认的报废单 |
| 报损出库单 | ✅ | 可反确认已提交/已确认的报损单 |
| 调拨单 | ✅ | 可反确认已提交/已确认的调拨单 |

### 8.3 操作规则

| 当前状态 | 反确认后状态 | 库存变化 | 冲销流水 |
|---------|------------|---------|---------|
| 已提交 (submitted) | 待审核 (pending) | 无变化 | 无 |
| 已确认 (confirmed) | 待审核 (pending) | 回滚库存 | 生成冲销流水 |

### 8.4 注意事项

1. **反确认时机**：反确认按钮在单据状态为"已提交"或"已确认"时显示
2. **库存回滚**：已确认的单据反确认时，系统会自动回滚库存数量，并生成冲销流水记录
3. **库存校验**：反确认回滚库存时，如果仓库不允许负库存，则回滚后库存不能为负
4. **冲销记录**：已确认单据反确认会生成 `transactionType: 'reversal'` 的库存流水，关联原流水记录的 `reverseTransactionId`

### 8.5 操作步骤

1. 在单据列表中找到需要反确认的单据
2. 点击操作列的"反确认"按钮
3. 在确认弹窗中点击"确认"
4. 系统自动执行反确认操作，更新单据状态和库存数据
