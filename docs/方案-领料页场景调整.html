五、数据流 & 计算逻辑（含场景 4 合并）

场景 1/2/3 公式：
实际调度数量 = editItem.details[i].quantity  （可调输入框里的值，用户可改）
默认值 = workOrderQty（作业数量）× product.ratio（配置里的比例）
🎯 场景 4 合并算法：
groupBy(workItemName) → {
  workOrderQty: sum(各工单 workOrderQty),
  products: reduce(各工单 products, (acc, p) => {
    acc[p.productId] = acc[p.productId] ? { ...p, ratio: Math.max(acc[p.productId].ratio, p.ratio) } : p
  })
}
→ 实际数量 = 合并后总作业数 × ratio
