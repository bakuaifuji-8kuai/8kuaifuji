# 本周更新清单（2026-10-21 至 2026-10-24）

---

## 🗓 10月21日（周二）

### 一、新增「自由审批流」功能模块

系统以前的审批是固定流程，管理员改不了节点顺序。这次上线了一套自由审批流引擎：

- 管理员可以在后台自定义审批流程（比如"物资采购审批"、"费用报销审批"），灵活配置节点数量、每个节点的审批人角色
- 业务人员发起审批时，选择对应流程，填标题、内容、上传附件，提交后系统按节点自动依次流转
- 每个节点审批人可以"通过"、"驳回"或"退回上一步"，每次操作记录审批人、时间、意见
- 整条流程的状态机：草稿 → 审批中 → 通过 / 驳回 / 退回

### 二、新增「展会物资调拨还库」页面

展会筹备期间，物资会临时从仓库调到展会现场。展会结束后需要走还库流程：

- 可以创建调拨单：选源仓库、填展会名称、目标仓库（一般就是源仓库本身）
- 物资明细逐行填调拨数量，支持多物资混拨
- 调拨审批通过后，源仓库库存自动扣减
- 还库时物资回到原仓库，库存自动恢复

### 三、新增「供应商账号管理」能力

之前供应商只有名称和联系方式，没有登录账号。这次给供应商加了独立账号体系：

- 管理员可以为每个供应商创建多个登录账号（比如现场对接员一个、文员一个）
- 账号支持启用/禁用、重置密码
- **供应商自己不能改密码**，密码统一由管理员管理
- 预置了 5 家示例供应商账号方便演示

### 四、采购计划表头分组调整

月度采购计划表原来只有两段（前期准备 → 招标采购阶段），现在拆成三段：

- **前期准备**（不变）
- **招标采购准备阶段**（新增）：把「采购方式选择」和「佐证资料」从下面拆出来放这里。因为采购方式应该在启动招标之前就定好，不能混在"招标阶段"里
- **招标采购阶段**（原来的阶段，去掉拆走的两项）

### 五、业主代表输入框联动

招标表单里，"是否委派业主评委"下拉选"否"时，"业主代表姓名"和"业主代表电话"两个输入框自动隐藏；选"是"才显示并要求必填。避免用户选了"不委派"还得填代表信息的困惑。

### 六、招采执行全流程升级

- 报名单位 Tab 改名为「招标竞争」，支持"公开招标"和"邀请招标"两种模式下的报名单位列表
- 新增「招标答疑」模块：记录答疑时间、答疑人、问题列表（问题+答复）
- 新增「审批材料」模块：上传各类需要审批的附件清单
- 目录内比价工单增加保存校验：受邀供应商数组不能为空，否则不让保存

### 七、电子商城采购升级

- 电子商城的采购明细表格加了「单价备注」列，每行可以手填说明这个单价的依据
- 电子商城来源的采购，自动排除在"招采合同签订"流程之外（电子商城走的是另一条合同路径）
- 合同采购订单页面增加"采购方式"过滤条件，可以只看电子商城来源的订单

### 八、合同表单精简

自办展、合办展的合同表单里，整段删除了 3 个业务上已确认不需要的字段：
- ~~履约评价~~
- ~~考核管理~~
- ~~年度评价~~

### 九、新增两份业务流程图

到 `docs/` 目录可以下载：
- `招采计划全流程说明.xlsx`
- `招采执行全流程说明_操作指南.xlsx`

## 🗓 10月22日（周三）

### 一、物资申请 → 物资档案自动打通

之前物资申请审批通过后，物资档案还得手动建一条。这次改成自动生成：

- 物资申请明细里新增「类别」下拉选择（比如工程类、办公类、设备类、耗材类）
- 审批通过时，系统自动遍历每条申请明细，根据类别生成带前缀的编码（工程类 G-0001、办公类 O-0002），写入物资档案库
- 编码唯一性保证：同批次导入会跟踪已生成的编码，冲突时自动顺延

### 二、物资申请 Excel 导入强校验

重构了物资申请的 Excel 导入逻辑：

- **表头兼容**：支持"类别名称"、"类别"、"物资类别"三种不同写法
- **类别必填校验**：导入时每行的类别必须能匹配到系统里已有类别，否则该行报错
- **重复物资模糊检测**：导入前先和现有物资档案做名称相似度比对，如果有 80% 以上可能是重复的，弹窗列出所有疑似项让用户手动确认
- **错误预览 Modal**：导入完成后弹出预览表格，成功行绿色背景，失败行红色并标注具体原因（比如"类别'工程类办公'不存在"）

### 三、采购计划表校验 + 佐证资料改为附件上传

- 月度计划表每行的「采购方式」改成必填项，保存时如果发现有行没选采购方式，弹提示"第 N 行「XXX」采购方式必填"
- 佐证资料从原来的文本描述框，改成**每行独立的附件上传**（支持 PDF/图片/Word），每件附件记录文件名、大小、上传人和上传时间

### 四、招采计划页顶部简化

原来页面顶部有一个"需求部门"手动输入框，现在整个删除，需求部门改成**系统自动从当前登录人的部门带出**，用户不需要手动填写也不能改。

## 🗓 10月23日（周四）

### 一、🆕 供应商报价模拟手机端（重点功能）

这是本周最大的新功能，花了一整天写的：

- **模拟一个 375×720 的手机界面**，有 iOS 状态栏（9:41）、顶部导航栏、Tab 切换（待报价 / 已报价）、底部身份切换
- **6 家预置模拟供应商**：湖南展台搭建（王经理）、长沙展架供应（李总）、宏远展览物资（张采购）、会展设备租赁（陈主管）等，底部下拉可以切换身份，localStorage 记住选择
- **工单智能过滤**：当前登录供应商只会看到"自己被邀请 + 报价截止时间没过期 + 属于目录内比价"的工单
- **防重复报价**：同一供应商对同一工单只能报一次，已报过的会自动排除在"待报价"列表外
- **报价视角自动切换**：
  - 物资采购类 → 按物资逐行报价（卡片显示物资编码、名称、规格、单位、数量、报价上限）
  - 工程施工 / 服务项目类 → 按项目明细报价（卡片显示项目名称、概况、价格方式）
- **四种价格方式的不同报价 UI**：
  - 固定单价 → 输入含税单价 + 自动算金额
  - 费率结算 → 输入费率（元/月）+ 月数
  - 按量结算 → 输入单价 + 预估量
  - 按次计费 → 输入单次报价 + 次数
- **超限单价红色告警**：输入的单价如果超过了采购方设定的上限，右侧显示红色 ⚠️ 标注，但不会强制禁止（让供应商自己决定要不要报）
- **数据实时闭环**：提交报价后，PC 后台的「目录内供应商报价」页面会立刻联动显示这条新报价
- **入口**：侧边栏 → 招采实施过程管理 → 📱 供应商端模拟；或者在"报价管理"页面顶部点"📱 进入供应商端模拟"按钮

### 二、库存查询：期初库存 Excel 导入

系统初始化时可以批量导入已有库存数据，不用一条一条手动录：

- **下载模板**：一键生成含说明行的 Excel 模板，列顺序为：物资编码（必填）、物资名称、规格型号、仓库名称（必填）、仓位名称、批次号、数量（必填）、入库日期（必填）、备注
- **模板自动带入系统已有数据**：仓库列自动列出所有已有仓库名称（比如"主仓库、设备仓"），物资编码列自动用系统里的第一条示例物资
- **导入预览 Modal**：选文件 → Excel 解析 → 表格预览（成功行绿色、错误行红色+具体原因）→ 确认后批量写入
- **校验项**：物资编码必须匹配已有物资、仓库名称必须匹配已有仓库、数量 ≥ 0、入库日期格式合法

### 三、物资档案 Excel 导入升级

- **下载模板加「类别」必填列**：模板从 5 列变 6 列，第一列就是"类别（必填）"
- **模板里自动列出可选类别值**：说明行写着"可选值：工程类、办公类、设备类、耗材类"（动态取系统已配置的类别）
- **导入时自动按类别前缀生成编码**：工程类 → G-0001、办公类 → O-0002、设备类 → D-0003、耗材类 → H-0004
- **编码唯一性保证**：跟踪已使用的编码，同批次导入冲突时自动顺延

### 四、采购数量列改为可编辑

采购需求申请页面里有 3 张明细表格，每张表的"采购数量"列原来只是纯文本显示，现在改成了可编辑的数字输入框（`type="number" min="0" step="1"`）。改了数量系统自动保存，不需要再删行重建。
